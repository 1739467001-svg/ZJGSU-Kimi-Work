`DUSK_BEFORE_SUNSET_MIN = 25` 改为 `NIGHT-侧偏移`(如日落 +10 分钟)一行即可,数据已备查。

## 五、黎明/黄昏观感强化(SkyRig goldenGlow)

新增 `goldenGlow = clamp(1 - |altDeg|/6, 0, 1)`:高度角 -6°~+6° 区间峰值在地平线,日出日落对称。
在既有 duskGlow(nf 中点 ≈ -3°)基础上,额外覆盖太阳仍在地平线上的 golden hour:

- `rayleigh += 1.3 × goldenGlow`(地平线暖色散射增强)
- `turbidity += 1.5 × goldenGlow`(低日大气浊度/金色霾感)
- `mieCoefficient += 0.0025 × goldenGlow`(太阳周边金色光晕)
- `uSkyExposure -= 0.06 × goldenGlow`(橙金色更浓郁)
- 太阳色温曲线 `1 - alt/25` → `1 - alt/20`(低角度更快转暖)

两端保护:正午(10:00-15:00,杭州今日 alt 24°~83°)|alt|>6 → goldenGlow=0,湛蓝天空不变;
深夜 alt≈-17° → goldenGlow=0,rayleigh/浊度/mie/曝光仍为夜晚端点值,全黑星空夜景不变。
